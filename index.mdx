## Getting an API key

The LoyaltyDog API uses bearer-token authentication. Create a dashboard [API Key](https://app.loyalty.dog/account/appkeys) (JWT). `POST /appkeys` is dashboard-only and still mints JWTs — there is no public hashed-key issuance API.

<Tip>
  Already have a key? Jump straight to the [Quickstart](/quickstart) or the [Authentication](/authentication) guide.
</Tip>
