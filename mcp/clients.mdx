---
title: "Connect an MCP client"
description: "Wire the LoyaltyDog MCP server into Claude Desktop, Claude Code, Cursor, and Windsurf."
---

After you can run [`uvx loyaltydog-mcp`](/mcp/installation), add the server to your AI assistant.

Replace `your_key_here` with your bearer secret. Prefer an `ld_test_` key until you trust the assistant with live data. `LOYALTYDOG_API_TOKEN` still works when `LOYALTYDOG_API_KEY` is unset.

## Claude Desktop

Edit `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json
{
  "mcpServers": {
    "loyaltydog": {
      "command": "uvx",
      "args": ["loyaltydog-mcp"],
      "env": {
        "LOYALTYDOG_API_KEY": "your_key_here"
      }
    }
  }
}
```

Restart Claude Desktop after saving.

## Claude Code (CLI)

From any project directory:

```bash
claude mcp add loyaltydog --env LOYALTYDOG_API_KEY=your_key_here -- uvx loyaltydog-mcp
```

## Verify

In your AI assistant, ask:

> "List my LoyaltyDog programs."

The assistant should call `list_programs` and return programs that belong to that token.

<Tip>
  If the client cannot find the server, confirm `uvx` is on the `PATH` the client uses. Install uv from [https://docs.astral.sh/uv/getting-started/installation/](https://docs.astral.sh/uv/getting-started/installation/), then open a new terminal. `pipx run loyaltydog-mcp` or an installed `loyaltydog-mcp` can replace `uvx` as the command.
</Tip>
