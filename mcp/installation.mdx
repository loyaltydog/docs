The LoyaltyDog MCP server is the `loyaltydog-mcp` package. Your AI client starts it locally. You do not clone the API repository.

## Prerequisites

- Python 3.10 or later. [uv](https://docs.astral.sh/uv/) is the simplest way to run the package.
- A LoyaltyDog bearer token. See [Authentication](/authentication).
- An MCP client such as Claude Desktop, Claude Code, Cursor, or Windsurf.

`ld_live_` and `ld_test_` keys need an API Access subscription and the scope for each tool. A JWT app key keeps its current access and does not need that subscription. The server forwards whichever bearer secret you set. It does not check the subscription itself.

## Install

Run it without a permanent install:

```bash
uvx loyaltydog-mcp
```

Or with pipx:

```bash
pipx run loyaltydog-mcp
```

Or install it into the current environment:

```bash
pip install loyaltydog-mcp
loyaltydog-mcp
```

The process speaks MCP on stdin and stdout and waits for a client. `loyaltydog-mcp --version` prints the installed version and exits.

## Configure

Set these variables in the MCP client's `env` block. The installed command does not read a `.env` file.

| Variable | Required | Purpose |
| -------- | -------- | ------- |
| `LOYALTYDOG_API_KEY` | Yes | Bearer secret. An `ld_live_` key, an `ld_test_` key, or a JWT app key. |
| `LOYALTYDOG_API_URL` | No | API base URL. Default `https://api.loyalty.dog/v2`. A trailing slash is removed. |
| `LOYALTYDOG_API_TOKEN` | No | Older name for the same secret. Used only when `LOYALTYDOG_API_KEY` is unset. |

The server starts and lists its tools even when the key is missing. The first tool call then tells you to set `LOYALTYDOG_API_KEY`. The key is sent only as the bearer token.

<Note>
Package 0.1.0 is the current PyPI release. `list_program_rules`, phone search, and `lookup_gift_card_balance` arrive in the next release. See [MCP overview](/mcp/overview).
</Note>
