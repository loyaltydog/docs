This guide walks you from a dashboard App Key to a working public read.

## Prerequisites

- A LoyaltyDog merchant account and a dashboard [App Key](https://app.loyalty.dog/account/appkeys).
- `curl` or any HTTP client.

Dashboard App Keys today are **JWTs**. Copy the token once. There is **no** public issuance API for hashed `ld_test_` / `ld_live_` secrets. `POST /appkeys` is dashboard-only and **keeps minting JWTs**.

## 1. Set your credentials

```bash
export LOYALTYDOG_API_KEY="paste-your-dashboard-jwt-here"
export LOYALTYDOG_API_URL="https://api.loyalty.dog"
```

<Warning>
  Never commit tokens to source control. Use a secrets manager, environment variables, or your CI secret store.
</Warning>

## 2. List loyalty programs

Public product routes are under **`/v2`**, not `/api/v2`.

```bash
curl -sS -D - \
  -H "Authorization: Bearer ${LOYALTYDOG_API_KEY}" \
  -H "Accept: application/json" \
  "${LOYALTYDOG_API_URL}/v2/loyalty/programs"
```

A successful call returns a JSON array of program objects. An empty list `[]` is success with no programs yet.

JWT App Keys have implicit full merchant access. A hashed `ld_*` key needs the `loyalty:read` scope (otherwise 403). Unscoped identity ping: `GET /v2/token`.

### JavaScript (`fetch`)

```javascript
const API = "https://api.loyalty.dog";
const key = process.env.LOYALTYDOG_API_KEY;

const res = await fetch(`${API}/v2/loyalty/programs`, {
  headers: {
    Authorization: `Bearer ${key}`,
    Accept: "application/json",
  },
});

if (!res.ok) {
  throw new Error(`${res.status} ${await res.text()}`);
}

const programs = await res.json();
console.log(programs);
```

### Python (`requests`)

```python
import os
import requests

API = "https://api.loyalty.dog"
key = os.environ["LOYALTYDOG_API_KEY"]

res = requests.get(
    f"{API}/v2/loyalty/programs",
    headers={"Authorization": f"Bearer {key}", "Accept": "application/json"},
    timeout=30,
)
res.raise_for_status()
print(res.json())
```
