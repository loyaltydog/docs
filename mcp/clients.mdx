---
title: "Connect an MCP client"
description: "Add the LoyaltyDog MCP server to Claude Desktop, Claude Code, Cursor, Windsurf, and other MCP clients."
---

Once you have [installed the MCP server](/mcp/installation), add it to your AI assistant.

Set `LOYALTYDOG_API_KEY` to your public API key (`ld_live_…` or `ld_test_…`) or to a JWT app key. `LOYALTYDOG_API_URL` is optional. It defaults to `https://api.loyalty.dog/v2`. `LOYALTYDOG_API_TOKEN` still works when `LOYALTYDOG_API_KEY` is unset.

## Claude Desktop

Edit `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json
{
  "mcpServers": {
    "loyaltydog": {
      "command": "uvx",
      "args": ["loyaltydog-mcp"],
      "env": {
        "LOYALTYDOG_API_KEY": "ld_live_your_key_here"
      }
    }
  }
}
```

Restart Claude Desktop after saving.

## Claude Code

From any directory:

```bash
claude mcp add loyaltydog --env LOYALTYDOG_API_KEY=ld_live_your_key_here -- uvx loyaltydog-mcp
```

## Other MCP clients

Use the same stdio command in any client that launches a local MCP server:

```json
{
  "command": "uvx",
  "args": ["loyaltydog-mcp"],
  "env": {
    "LOYALTYDOG_API_KEY": "ld_live_your_key_here"
  }
}
```

<Note>
  If the client cannot find `uvx`, a GUI app may not inherit your shell `PATH`. Run `which uvx` and set `command` to that absolute path. Or run `pip install loyaltydog-mcp` and set `command` to the absolute path of `loyaltydog-mcp` (`which loyaltydog-mcp`).
</Note>

## Verify

In your AI assistant, ask:

> "List my LoyaltyDog programs."

You should see the assistant call the MCP server and return data scoped to your API key.
