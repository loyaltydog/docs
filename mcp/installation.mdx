---
title: "Install the MCP server"
description: "Install and configure the LoyaltyDog MCP server with uvx, pipx, or pip."
---

Install the `loyaltydog-mcp` package. Your MCP client starts the `loyaltydog-mcp` console script.

## Prerequisites

- Python 3.10 or later.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) (recommended). `pipx` and `pip` also work.
- A public API key that starts with `ld_live_` or `ld_test_`. Create the key in the LoyaltyDog dashboard. See [plans and sign-up](https://loyaltydog.ai/pricing/).
- An MCP client such as Claude Desktop, Claude Code, Cursor, or Windsurf.

## Install

`uvx` is the recommended way to run the server. It downloads `loyaltydog-mcp` and starts the console script.

<CodeGroup>

```bash uvx
uvx loyaltydog-mcp
```

```bash pipx
pipx run loyaltydog-mcp
```

```bash pip
pip install loyaltydog-mcp
loyaltydog-mcp
```

</CodeGroup>

## Configure

Set these environment variables in your MCP client, or export them in your shell before a manual check.

| Variable | Required | Description |
| --- | --- | --- |
| `LOYALTYDOG_API_KEY` | Yes | Public API key from the LoyaltyDog dashboard. Starts with `ld_live_` or `ld_test_`. |
| `LOYALTYDOG_API_URL` | No | API base URL. Defaults to `https://api.loyalty.dog/v2`. |

`LOYALTYDOG_API_TOKEN` still works as a legacy alias for `LOYALTYDOG_API_KEY`.

<Note>
  The server starts without `LOYALTYDOG_API_KEY` and still lists its tools to the client. A tool call without a key returns a clear error.
</Note>

## Sanity check

Print the version:

```bash
LOYALTYDOG_API_KEY=ld_test_your_key_here uvx loyaltydog-mcp --version
```

Running `uvx loyaltydog-mcp` with no arguments waits for an MCP client on stdin. Press Ctrl+C to quit. `pipx run loyaltydog-mcp` and `loyaltydog-mcp` behave the same way.

## Upgrade

<CodeGroup>

```bash uvx
uvx loyaltydog-mcp@latest
```

```bash pip
pip install -U loyaltydog-mcp
```

</CodeGroup>

`uvx loyaltydog-mcp@latest` resolves the latest release and then starts the server. Press Ctrl+C to quit.
